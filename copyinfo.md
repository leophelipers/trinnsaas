# PERGUNTAS FREQUENTES

## Preciso pagar uma mensalidade para participar?

Não. A proposta da parceria não é vender uma assinatura tradicional para o infoprodutor. A estrutura é construída através de um modelo de coprodução, conforme o projeto e o potencial da parceria.

## Posso usar a Kriativa para criar meu próprio produto?

Sim. A proposta é que você possa utilizar a infraestrutura de inteligência artificial também na sua própria operação, para criação de conteúdos, materiais, produtos, campanhas e experiências.

## Meus alunos terão acesso à Kriativa?

Essa é uma das possibilidades da parceria. A estrutura pode ser desenhada para que a Kriativa faça parte da experiência entregue aos seus alunos.

## Preciso ter um curso pronto?

Não necessariamente. Podemos avaliar diferentes formatos de parceria, desde produtos já existentes até novos projetos que possam ser construídos utilizando inteligência artificial.

## Posso usar a Kriativa para outros projetos da minha empresa?

A estrutura da parceria será definida de acordo com cada projeto. O objetivo é criar uma relação que faça sentido para os dois lados.

## Qual é o percentual da coprodução?

Não existe uma porcentagem única para todos os parceiros. A divisão é definida de acordo com o produto, audiência, operação, modelo de negócio e participação de cada parte.

## Existe garantia de aprovação?

Não. As parcerias passam por uma análise individual. Queremos trabalhar com projetos em que exista potencial real para os dois lados.
